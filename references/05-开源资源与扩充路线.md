# 开源资源与扩充路线

本文件说明在撰写与扩充本 Skill 时，可参考的开源资源、应遵循的数据标准、扩充新典籍的步骤，以及引入外部资源时的审查要点。开源资源只作考据与结构参考，其内容要经本 Skill 的原创改写后才能写入，不得直接搬运。

## 一、开源资源能做什么、不能做什么

开源资源的价值在于：快速定位典籍版本、核对篇目结构、发现遗漏的典籍、借鉴知识组织方式。

开源资源不能替代本 Skill 的原创工作：古籍原文要逐字核对，白话解释要原创重写，辨证逻辑要按本 Skill 的五格坐标法组织。任何外部资源进入本 Skill 前，都要走一遍审查要点。

## 三、数据标准

引入任何外部数据前，先确认它满足以下标准，不满足的不用。

**版本标准**

- 每条数据必须能指回具体典籍的具体篇名或条文号。
- 每条数据必须注明底本或版本系统，版本不明的标"待核"。
- 原文短句须经"三步核对"（见 `references/04-来源版本与版权.md`）确认无一字讹误。

**原创标准**

- 白话解释必须原创重写，禁止搬运任何现代注本、译本、数据库的整段文字。
- 结构化条目（证型、方证表）可参考外部项目的组织方式，但具体内容按本 Skill 五格坐标法重写。

**许可标准**

- 优先采用公有领域或 CC-BY、CC-BY-SA 类许可的资源。
- 采用 CC-BY-NC 类许可的资源，仅借鉴其思路，不复制其数据，且本 Skill 输出不涉及商业用途时也需保留署名。
- 不使用任何来源不明、许可不清的数据集。

**安全标准**

- 引入的方剂只列组成药味与出处，不提供可自行抓药的剂量。
- 引入的药材涉及法规禁用或剧毒品种的，按 `references/06-安全边界与输出规范.md` 的药材风险分级处理，只作知识说明，不推荐自行使用。

## 四、扩充新典籍的步骤

按以下六步把一部新典籍纳入本 Skill，顺序不能颠倒。

1. **登记版本。** 在 `references/04-来源版本与版权.md` 的版本考据总表加一行，写明书名、年代、作者、卷数结构、底本与主要版本、备注。
2. **定位合法来源。** 找到该典籍的公有领域原文或馆藏影像，确认可合法获取的途径，记入合法获取途径。
3. **核对原文。** 按"三步核对"逐条核对将要引用的原文短句，确保无一字讹误。
4. **撰写分册。** 按统一模板写新分册，包含：一句话说明、全书骨架、核心理论条目（原文短句＋出处＋大白话＋怎么用）、辨证或方证表、误读与版本差异、待核清单。模板参照 `references/01-医经与诊断.md`、`references/02-本草与经方.md` 等既有分册。
5. **补进速查表。** 把新增的证型补进 `references/07-症状辨证速查.md`，并标明依据分册。
6. **登记索引并递增版本。** 在 `SKILL.md` 的资料索引表加一行，递增 `version`，在 `references/04-来源版本与版权.md` 追加变更记录。

## 五、引入外部资源的审查要点

每引入一份外部资源，逐项过一遍，任何一项不过就退回重做。

**来源审查**

- 资源来源是否公开可查，是否有明确的项目主页或数据出处。
- 是否有许可声明，许可类型是什么，是否与本 Skill 的 CC-BY-SA-4.0 兼容。

**内容审查**

- 所引原文是否为公有领域，是否已过"三步核对"。
- 是否存在整段复制现代注本、译本、数据库内容的情况，有则改写为原创。
- 方剂组成是否只列药味、不含自行抓药剂量，剂量是否标注由医师核定。

**安全审查**

- 是否包含法规禁用药材、剧毒药材，有则按药材风险分级处理。
- 是否把祝由、鬼胎、以形补形等时代性内容当作现代可用方法，有则只标为历史记载。
- 辨证结论是否有典籍依据支撑，无依据的删去或标"待核"。

**结构审查**

- 新增内容是否符合五格坐标法的辨证逻辑，是否与既有分册的体例一致。
- 新增证型是否已补进速查表，资料索引是否已更新。

## 六、持续扩充的方向

本 Skill 的覆盖范围按以下顺序持续扩展，每扩展一部都走一遍第四、五节的流程。

1. **补齐既有重点典籍的细目。** 对已收录的典籍，继续补充核心条文、方证、误读辨析，加深理解。
2. **扩充其他经典医籍。** 如《医宗金鉴》《景岳全书》《医林改错》《血证论》《温热经纬》等，按其学术价值与用户需求排序纳入。
3. **引入专科典籍。** 如外科、儿科、眼科、喉科等专科古籍，补齐各专科的辨证依据。
4. **完善方证与证型映射。** 把更多方剂的方证与证型对应关系结构化，提升速查效率。

每完成一轮扩充，递增版本号并记录变更，保持 Skill 的可追溯与可维护。
