# 针灸专科与经络取穴

本分册在分册第11册针灸总论基础上，补充经络辨证框架与"症状到取穴方向"的检索主线。针灸以经络脏腑为诊，以腧穴手法为治，属专业医疗行为。

## 一、核心典籍与版本

1. 《黄帝内经·灵枢》（战国至汉，托名黄帝，约成书前 1 世纪）
   针灸理论渊薮，论经脉、营卫、针法、五输，今以《灵枢经》通行本为据。
2. 《针灸甲乙经》（晋，皇甫谧，282 年，十二卷）
   现存最早的针灸专著，集《内经》针灸条文并明定位主治，为针灸定典。
3. 《铜人腧穴针灸图经》（宋，王惟一，1026 年）
   铸铜人、绘经络腧穴，统一腧穴定位，为腧穴标准化之始。
4. 《针灸大成》（明，杨继洲，1601 年，十卷）
   汇明以前针灸文献与家传经验，论下手八法、十二字手法、子午流注，集大成之作。现代以人民卫生出版社点校本为据。

## 二、经络脏腑辨证框架

- 十二正经与任督二脉：气血运行主干，每经联属一脏一腑，病候沿经分布。
- 标本根结、俞募配穴：背俞穴（膀胱经）与腹募穴（脏腑募）前后呼应，调脏腑虚实。
- 原络配穴、八脉交会：原穴调本经、络穴通表里；八脉交会穴统奇经。
- 子午流注与灵龟八法：按气血时辰流注选穴的时间治疗学，须由执业针灸师据证施行。

## 四、与五格坐标映射

- 针灸辨证仍以五格坐标为总纲：先定病位在何经何脏，再定病性虚实寒热。
- 例：胃脘痛属"位置 脾胃、性质 寒、力量 虚"则温针灸足三里、灸中脘；属"热实"则针泻内庭、梁丘。

## 五、安全边界

- 针灸、推拿、拔罐、刮痧均属专业医疗行为，本技能只讲典籍理论与取穴方向，绝不指导自行针刺。
- 胸背、延髓、大血管处等危险穴位禁擅自深刺，须由执业针灸师操作。
- 子午流注、灵龟八法依时辰取穴，现代应用须专业判断，不可机械套用。
- 晕针、断针、感染等为针灸风险，须在有资质机构由执业人员施行。

## 六、待核清单

- 各穴定位与主治须回《针灸甲乙经》《铜人图经》及现行针灸学教材核对。
- 杨继洲下手八法、十二字手法的具体次序须由执业针灸师解读。
- 现代针灸临床方案（如醒脑开窍针法）属当代经验，引用须注明并衔接规范诊疗。
