# 日本汉方

本分册收录三部日本汉方代表作：吉益东洞《类聚方》、浅田宗伯《勿误药室方函》、汤本求真《皇汉医学》。日本汉方以中国《伤寒论》《金匮要略》为根，发展出"方证相对"的务实路线，是总纲辨证之外"从证（腹证）直接到方"的强力补充。

## 一、类聚方（日本，吉益东洞，1702 至 1773，宝历年间成书）

**一句话说明**：吉益东洞是日本古方派中坚，把《伤寒论》《金匮要略》的方按"方"重新归类，附仲景原文与按语，开创"方证相对"特色。

**全书骨架**：选录《伤寒论》《金匮要略》方剂 220 余首，依方类聚，每方后集原书各篇应用该方的辨证条目，再附作者考证与按语，按语多为方证内涵解析。另有《药征》《药征续编》考药物功效。

**核心理论条目**

1. 吉益东洞："医之学也，方焉耳。"（医学就在于方）
   白话：医学的落脚点就是方剂，把精力放在把准方剂的适应证上。用在：理解古方派"以方统证"的思路，与重理论推演的路子不同。
2. 吉益东洞："理无定准，疾有定证，岂可以无定准之理，临有证之疾哉。"
   白话：理论没有固定标准，但疾病有固定的证象，不能用飘忽的理论去套实在的证。用在：强调亲验实证，反对空谈玄理。
3. 东洞排除《内经》阴阳五行脏腑经络的解释体系，以腹诊、方证为凭。
   白话：他只看实际证象与腹证，不靠五行生克说理。用在：知道古方派是"重实证、轻思辨"的一支，取其方证精确实用之处，理论框架仍归本 Skill 的五格坐标法。

**对 Skill 的价值**

- 把"有是证用是方"做到极致，与本 Skill 第 2 步"把症状填进五格坐标"互补：东洞派直接从腹证、主症定方，少一层理论转手。
- 其《药征》以方证反推药效的方法，可辅助理解药物在何种证下才用。

**误读与边界**

- 古方派否定阴阳五行理论，与中国主流"病机辨证"互补但不互代；本 Skill 仍以五格坐标法为总纲，方证相对作为快速通道。
- 腹诊为专业手法，本 Skill 不指导自行腹诊，只作知识参考。

## 二、勿误药室方函（日本，浅田宗伯，1815 至 1894，明治年间）

**一句话说明**：浅田宗伯是日本汉方最后巨擘、折衷派代表，取古方为主、后世方为用，载方约 579 至 600 首，重"圆机活法"。

**全书骨架**：《方函》收方 600 余首，《口诀》解说药物配合妙用与临证心得。书名"勿误"取自《伤寒论》"常须识此，勿令误也"，宗伯字"识此"亦源于此，强调对症用药、不可误治。

**核心理论条目**

1. 浅田宗伯医则："以古法为主，后世方为用。"
   白话：以《伤寒论》《金匮》的古法为根本，后世方作为补充运用。用在：理解折衷派的兼容立场，既守仲景又用后世经验。
2. 宗伯以"脉、病、证、治"课徒：先详脉，因脉识病，因病辨症，随证施治。
   白话：诊断分四步，脉定病、病定证、证定治，像提网的总绳一样有条理。用在：与五格坐标法的"采集到坐标到治法"异曲同工，可互相印证。
3. 宗伯以画彩喻用药："寒热温凉者，药之性也；大小刚柔奇偶轻重者，医师配合之妙也。"
   白话：药的寒热温凉是本性，怎么搭配出巧妙疗效靠医师的配伍。用在：强调方剂是整体配合，不能只盯单味药性。

**对 Skill 的价值**

- "常须识此，勿令误也"提醒辨证每一步都要对证，正合本 Skill 的安全闸门精神。
- 折衷派兼容古方与后世方，拓宽了方证来源，可作为补充检索路径。

**误读与边界**

- 浅田宗伯批评古方派"不讲究药物性味、一药主治一证"的偏颇，说明单靠方证也有局限，须回到整体辨证。
- 所载方含日本经验方，引用须注明来源，且剂量须医师核定。

## 三、皇汉医学（日本，汤本求真，成书 1927 年）

**一句话说明**：汤本求真原为西医，后转学中医，以《伤寒论》《金匮要略》为主干，结合西医病理注释，是中日医学对话的桥梁之作。

**全书骨架**：分三卷。先总论阴阳、虚实、表里等理论，述脉诊、腹诊；后按方剂主治证候分类，多以六经体系为主，每方注药效并搜罗中日治验，作者加按语。

**核心理论条目**

1. 汤本求真以《伤寒论》《金匮要略》为全书中心，强调"方证对应"的诊疗思路。
   白话：哪一套证象就用哪一首方，方与证严格对应。用在：与东洞方证相对一脉相承，强化"证方对应"的可操作性。
2. 汤本求真在治验中常以西医病名（如肺栓塞、结核性腹膜炎）解释中医方证。
   白话：用现代医学病名帮人理解古方适用情形。用在：作为"古籍证型"与"现代病名"之间的桥梁，但须以当下症状体征为准，不把现代病名等同证型（见 SKILL.md 硬性禁止）。

**对 Skill 的价值**

- 提供了"经方证型 ↔ 现代疾病"的对照视角，便于用户用现代语言理解古方适用场景。
- 治验案例丰富，可作速查时的旁证。

**误读与边界**

- 西医注释是汤本个人见解，现代病名与中医证型不可机械对应。
- 全书仍以仲景方为根，引用须注明出自《皇汉医学》而非直接当作中国古籍原文。

## 四、中日合参：方证相对与本 Skill 的关系

- 日本汉方的"方证相对"是五格坐标法的"快通道"：坐标填完得到证型，再用方证相对的思路直接锁定代表方。
- 二者差异：本 Skill 重病机推演与坐标定位，汉方重腹证与主症直断；合用时先走坐标定大方向，再用方证相对提速。
- 安全上完全一致：方证相对也要求"有是证用是方"，没有对应证象不可妄投，命中的红旗清单优先于一切方证。
