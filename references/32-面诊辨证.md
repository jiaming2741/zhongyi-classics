# 面诊辨证

本分册系统整理望诊中的面诊方法：从望神、望色、望形、望态，到面部脏腑分属、五色主病、五官望诊，最终落到与五格坐标、证型的对应路径。用户在病症咨询第一步提供面部照片时，按本册路径精确辨证。所有内容只引公有领域典籍原文短句，白话解释均为原创重写。

## 一、望诊总纲：四诊之首

- 典籍依据：《难经·六十一难》"望而知之谓之神，望见其五色，以知病所在"；《素问·脉要精微论》"夫精明五色者，气之华也"，望诊首重神色色泽。
- 总原则：望诊先望整体神色，再看局部形态色泽，最后与问诊切诊合参，单一面色不能定证。
- 与四诊关系：望诊信息最快最直接，但必须和问、切互证；面色可受光线、妆容、光照影响，须注明采集条件后再下判断。

## 二、望神（第一眼的精气判断）

望神看的是整体精神状态，是判断病情轻重与正气盛衰的第一关。

| 神态 | 表现 | 主病方向 | 白话 |
| --- | --- | --- | --- |
| 得神（有神） | 目光有神、表情自然、反应灵敏 | 正气未伤、病情轻 | 人精神头足，病多不重 |
| 少神 | 目光乏神、表情淡漠、倦怠乏力 | 气血亏虚、正气渐伤 | 人没劲儿、精神差，虚证多见 |
| 失神（无神） | 目光呆滞、表情淡漠或烦躁、反应迟钝 | 正气大伤、病情重 | 人已经明显不行了，病势重 |
| 假神 | 久病重病之人忽然精神转"好"、面红如妆 | 回光返照，危重信号 | 看着突然精神了，实际是危险信号，须立即就医 |

- 白话要点：望神看的是"亮不亮、活不活"，目光明亮灵活是正气足，目光呆滞无神要警惕病情加重。
- 典籍依据：《素问·脉要精微论》"五色精微象见矣，其寿不久也"，久病重病之人五色精微毕露、虚浮无根，即危重之兆，是假神（回光返照）判读的直接依据。
- 红旗衔接：假神、失神属危重信号，命中即停辨证、建议就医，与第06册红旗清单一致。

## 三、五色主病（面色辨病的核心）

面部色泽以青、赤、黄、白、黑五色为纲，各色对应不同的病性与病位。颜色判断须在自然光下进行，并排除妆容、灯光、肤色人种差异。

| 面色 | 主病 | 对应证型方向 | 白话 |
| --- | --- | --- | --- |
| 青色 | 寒证、痛证、血瘀、惊风 | 寒凝气滞、血瘀证、小儿惊风 | 面发青多是寒、痛、瘀，或小儿受惊 |
| 赤色 | 热证 | 实热、虚热 | 脸发红多是热，红得鲜亮属实热，午后颧红属虚热 |
| 黄色 | 脾虚、湿证、虚证 | 脾胃气虚、脾虚湿困、黄疸（阳黄阴黄） | 脸发黄多是脾虚或湿重；黄而明亮为湿热，黄而晦暗为寒湿 |
| 白色 | 虚证、寒证、失血 | 气血两虚、阳虚、失血 | 脸发白多是虚、寒，或失血之后 |
| 黑色 | 肾虚、寒证、水饮、血瘀 | 肾阳虚、肾阴虚、水饮内停、瘀血日久 | 脸发黑发暗多是肾的问题、寒重或久瘀 |

- 白话要点：五色对应大致规律是"青寒痛、赤热、黄虚湿、白虚寒、黑肾瘀"，再结合颜色的深浅、润燥细辨。
- 润燥细分：色润为气血尚通，色枯槁为精气大伤；面色鲜明多属新病实热，晦暗多属久病虚损。
- 典籍依据：《灵枢·五色》"青黑为痛，黄赤为热，白为寒"，又"以五色命脏，青为肝、赤为心、白为肺、黄为脾、黑为肾"；《素问·五脏生成》"生于心，如以缟裹朱，生于肺，如以缟裹红，生于肝，如以缟裹绀，生于脾，如以缟裹栝楼实，生于肾，如以缟裹紫，此五脏所生之外荣也"，并载五色生死之判："青如翠羽者生，赤如鸡冠者生，黄如蟹腹者生，白如豕膏者生，黑如乌羽者生；青如草兹者死，黄如枳实者死，赤如衃血者死，白如枯骨者死，黑如炲者死"。色润泽为生色，色枯槁为死色。

## 四、面部脏腑分属（局部定位看哪里）

面部各部位分属不同脏腑，局部色泽形态可定位病位，这是面诊与五格坐标"位置格"对接的桥梁。

| 部位 | 分属（《灵枢·五色》原文） | 病位指向 |
| --- | --- | --- |
| 庭（天庭、额部） | 庭者首面也 | 头面、上部问题 |
| 阙上（眉间上区） | 阙上者咽喉也 | 咽喉、上焦问题 |
| 阙中（眉间、印堂） | 阙中者肺也 | 肺气、呼吸道问题 |
| 下极（鼻根部） | 下极者心也 | 心、心神问题 |
| 直下（鼻柱） | 直下者肝也 | 肝气、肝火问题 |
| 肝左（鼻柱左侧） | 肝左者胆也 | 胆气、少阳问题 |
| 下（鼻头、鼻准） | 下者脾也 | 脾胃问题，鼻头色黄多脾虚湿困 |
| 方上（鼻翼旁） | 方上者胃也 | 胃腑问题 |
| 中央（面中、鼻旁） | 中央者大肠也 | 大肠、肠道问题 |
| 挟大肠（大肠两侧） | 挟大肠者肾也 | 肾、下焦问题 |
| 面王（鼻尖）以上 | 面王以上者小肠也 | 小肠、下焦问题 |
| 面王（鼻尖）以下 | 面王以下者膀胱子处也 | 膀胱、下焦水道问题 |
| 颧部 | 颧者肩也（后颧候肩背腋部） | 肩背、上部问题，两颧亦候肺胃 |
| 颐部（下颌） | 颐为肾之表，肾主骨 | 肾虚、下焦问题 |

- 白话要点：额红多心火，眉间色变多肺气问题，鼻头黄多脾虚，鼻翼旁红多胃热，各部位对照看，比只看整张脸更准。
- 另一分属（《素问·刺热论》）：五脏热病的面色先兆另有分属，"肝热病者左颊先赤，心热病者颜先赤，脾热病者鼻先赤，肺热病者右颊先赤，肾热病者颐先赤"，适用于外感热病判断。两套分属各有适用场景，《灵枢·五色》偏脏腑定位，《素问·刺热论》偏热病传变，面诊时按病种选用。
- 排布说明：《灵枢·五色》分属为原文排列，后世医家有补充与出入，本册以原文为准，结合临床通行说法对照使用。

## 五、面部形态望诊（看形不看色）

除颜色外，面部形态变化同样直接提示病机。

| 形态 | 表现 | 主病 | 白话 |
| --- | --- | --- | --- |
| 面浮肿 | 面部虚浮饱满、按之有痕 | 风水（风邪袭表）、水湿内停、脾肾阳虚 | 脸肿多为水湿，起病快多风邪，久肿多脾肾阳虚 |
| 面削（消瘦） | 面部肌肉塌陷、颧突 | 气血阴液亏虚、久病重病 | 脸明显瘦了、陷下去，是虚损已久 |
| 口眼歪斜 | 口角偏斜、眼睑闭合不全 | 中风（中经络）、风痰阻络、面瘫 | 突然嘴歪眼斜，中风或面瘫信号，须就医 |
| 面部抽搐 | 面肌不自主抽动 | 风动、肝风内动、血虚生风 | 脸上肌肉老抽，多是风动或血虚 |
| 痘痘、痤疮 | 面部丘疹、红肿 | 肺胃热盛、湿热蕴结 | 脸上长痘多肺胃热、湿热 |
| 斑（黄褐斑、白斑） | 面部色斑成片 | 肝郁气滞、气血瘀滞、脾虚湿蕴 | 脸上长斑多气滞血瘀或脾虚湿蕴 |

- 红旗衔接：突然口眼歪斜、半身不遂伴面部异常，按中风处理，立即就医（见第31册急症与红旗病种）。

## 六、五官望诊（开窍部位的细辨）

五官是脏腑的"窗口"，各窍的色泽形态直接对应脏腑虚实。

### 1. 目（肝开窍于目）

| 目象 | 主病 | 白话 |
| --- | --- | --- |
| 目赤肿痛 | 肝火上炎、风热上攻 | 眼睛红肿痛多肝火、风热 |
| 目眵多（眼屎多） | 肝经风热、上焦有热 | 眼屎多是上焦有热 |
| 目干涩 | 肝血不足、肝肾阴虚 | 眼睛干是肝血、肝肾阴亏 |
| 视物模糊 | 肝肾精亏、气血不足 | 看东西模糊多精血不足 |
| 目胞浮肿 | 脾虚湿盛 | 眼泡肿多脾虚水湿 |
| 目上视、斜视 | 肝风内动 | 眼睛上翻、斜视多肝风，须警惕 |

### 2. 鼻（肺开窍于鼻，鼻为脾候）

| 鼻象 | 主病 | 白话 |
| --- | --- | --- |
| 鼻流清涕 | 风寒、表寒 | 流清鼻涕多风寒 |
| 鼻流浊涕 | 风热、肺热 | 流黄鼻涕多风热、肺热 |
| 鼻翼扇动 | 肺热、肺气闭塞（重症） | 呼吸时鼻翼鼓动，肺热重或肺气不通畅 |
| 鼻头色红 | 脾胃有热 | 鼻头红多脾胃热 |
| 鼻头色黄晦暗 | 脾虚湿困、黄疸 | 鼻头黄而暗多脾虚湿重 |

### 3. 口唇（脾开窍于口，其华在唇）

| 唇象 | 主病 | 白话 |
| --- | --- | --- |
| 唇色淡白 | 血虚、气血两虚 | 嘴唇白多血虚 |
| 唇色红赤 | 热证 | 嘴唇红多热 |
| 唇色深红（如猪肝） | 热盛、血瘀 | 唇深红发暗多热盛或瘀 |
| 唇干裂 | 津液不足、燥热 | 嘴唇干裂多津伤、燥热 |
| 口角流涎 | 脾虚湿盛、风痰 | 嘴角流口水多脾虚或风痰 |
| 口唇生疮 | 脾胃热盛 | 嘴角长疮多脾胃热 |

### 4. 耳（肾开窍于耳）

| 耳象 | 主病 | 白话 |
| --- | --- | --- |
| 耳轮干枯焦黑 | 肾精亏虚、久病重证 | 耳朵干黑是肾精亏、病重 |
| 耳内流脓 | 肝胆湿热（脓耳） | 耳朵流脓水多肝胆湿热，须就医 |
| 耳郭淡白 | 气血不足、肾气虚 | 耳朵颜色淡多气血、肾气不足 |

## 七、面诊与五格坐标、证型的对应路径

面诊信息最终要落到辨证结论，按五格坐标逐格对接：

| 五格 | 面诊信息对应 | 示例 |
| --- | --- | --- |
| 位置 | 面部脏腑分属、五官分属 | 鼻头黄定位脾，两颧红定位肺胃或阴虚 |
| 性质 | 五色主病定寒热虚实 | 赤主热、白主虚寒、青主寒瘀 |
| 力量 | 望神与色泽润燥定虚实轻重 | 得神正气足，少神失神正气伤 |
| 物质 | 面部形态定物质层面变化 | 浮肿定水湿、面削定阴血亏虚 |
| 病因 | 形态与色泽反推病因 | 青主寒凝与瘀，黄主湿与虚 |

- 辨证路径：先望神定轻重，再按五色定寒热虚实，按分属定病位，按形态定物质与病因，五格信息合起来对候选证型，与第00册辨证总纲、第07册症状速查表、第33册舌诊互参。
- 与舌诊合参：面诊与舌诊信息互补，面诊偏整体与病位，舌诊偏寒热虚实与舌苔厚薄，两诊合参更准（见第33册）。

## 八、照片采集要求（第一步使用规范）

用户在病症咨询第一步提供面部照片时，按以下要求采集，确保辨证可靠：

| 要求 | 说明 |
| --- | --- |
| 光线 | 自然光或明亮均匀的室内光，避免黄光、强逆光、滤镜 |
| 角度 | 正面免冠照，额头、双颧、鼻、口唇、下颌完整入镜 |
| 妆容 | 素颜，不化妆、不戴浓妆，口红建议擦掉，避免遮盖唇色 |
| 背景 | 纯色简洁背景，避免大面积红黄等干扰色 |
| 时机 | 避免刚运动、饱餐、饮酒、情绪激动后拍照，尽量在平静状态 |
| 补充 | 如有局部特写（如眼、鼻、口唇、皮疹部位）可一并拍摄 |

- 使用方式：第一步了解情况时，自然引导用户提供面部照片，说明"拍张面部照片，我能看得更准"，不必解释内部辨证逻辑；拿到照片后按本册路径完成望诊，再与用户所述症状、舌象合参。
- 局限声明：照片受光线、角度、设备色彩影响，面诊结论须标注"基于照片、须面诊确认"，不能替代执业医师当面望诊。

## 九、安全边界（与第06册一致）

- 面诊只作为辨证的辅助信息，不替代当面望诊与四诊合参，照片辨证结论须标注局限。
- 望诊发现危重信号（假神、失神、突然口眼歪斜伴半身症状、严重黄疸）立即停止辨证、建议就医。
- 面诊结论须与问诊、舌诊、脉诊信息互证，单一面色、单一局部变化不能单独定证。
