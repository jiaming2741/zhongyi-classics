# 舌诊辨证

本分册系统整理舌诊辨证方法：舌的脏腑分属、舌质（色、形、态）、舌苔（色、质）、舌下络脉，以及舌象与寒热虚实证型的对应路径。用户在病症咨询第一步提供舌头照片时，按本册路径精确辨证。所有内容只引公有领域典籍原文短句，白话解释均为原创重写。

## 一、舌诊总纲

- 典籍依据：《灵枢·脉度》"心气通于舌，心和则舌能知五味矣""脾气通于口，脾和则口能知五谷矣"；《素问·阴阳应象大论》"心主舌""在窍为舌"；《素问·金匮真言论》"心开窍于舌"；《灵枢·五阅五使》"舌者，心之官也"；《灵枢·经脉》"脾足太阴之脉，入腹，属脾，络胃，上膈，挟咽，连舌本，散舌下""唇舌者，肌肉之本也"，肌肉软则舌萎；《灵枢·邪气脏腑病形》"其浊气出于胃，走唇舌而为味"。《伤寒论》以舌苔、口燥咽干辨热入阳明；温病学派（《温病条辨》《温热经纬》）以舌象为温热病辨证的要目。
- 总原则：舌诊先看舌质、后看舌苔，先看整体、再看局部，质苔合参，再与问诊脉诊互证。
- 舌质与舌苔分工：舌质（舌体）反映脏腑虚实、气血盛衰；舌苔反映病邪深浅、寒热燥湿。两者合看才能定证。

## 二、舌的脏腑分属与望舌部位

| 部位 | 分属 | 反映方向 |
| --- | --- | --- |
| 舌尖 | 心、肺 | 上焦心肺问题，舌尖红多心火、肺热 |
| 舌中 | 脾、胃 | 中焦脾胃问题，舌中黄腻多脾胃湿热 |
| 舌根 | 肾 | 下焦肾的问题，舌根苔少多肾阴亏 |
| 舌边 | 肝、胆 | 肝胆问题，舌边红多肝胆郁热 |
| 舌下络脉 | 气血运行 | 络脉粗曲发暗多瘀血、气滞血瘀 |

- 白话要点：舌尖看心肺，舌中看脾胃，舌根看肾，两边看肝胆，结合部位再看颜色苔质，定位更准。
- 典籍依据：舌面脏腑分候取《望诊遵经》"舌本在下，舌尖在上，舌中为内，舌边为外"之论，即舌尖属心肺、舌中属脾胃、舌根属肾、舌边属肝胆。舌为心之苗、脾之外候，由《灵枢·脉度》《素问·阴阳应象大论》《灵枢·五阅五使》等条文支撑（见本册一、总纲）。

## 三、舌质辨证（舌体看虚实与气血）

舌质从舌色、舌形、舌态三方面观察，是判断寒热虚实与气血津液状态的核心。

### 1. 舌色（主寒热、气血）

| 舌色 | 主病 | 对应证型方向 | 白话 |
| --- | --- | --- | --- |
| 淡白舌 | 虚证、寒证、气血两虚 | 气血两虚、阳虚、血虚 | 舌头颜色淡白，多是虚、寒、血不足 |
| 红舌 | 热证 | 实热、内热 | 舌头红，多是有热 |
| 绛舌（深红） | 热盛、热入营血 | 热入营血、阴虚火旺 | 舌头深红发亮，热势更重，温病多见 |
| 紫舌（紫暗、青紫） | 血瘀、寒凝、热盛动血 | 气滞血瘀、寒凝血瘀 | 舌头紫暗，多是瘀血或寒凝 |
| 舌有瘀斑瘀点 | 血瘀 | 气滞血瘀、瘀血内阻 | 舌头上有暗紫斑点，是瘀血的标志 |

- 典籍依据：《素问·热论》"伤寒五日，少阴受之，故口燥舌干而渴"，热盛津伤舌干之始；《素问·刺热》"肺热病者，先淅然厥，起毫毛，恶风寒，舌上黄，身热"，舌苔变黄主热之源；《灵枢·热病》"舌本烂，热不已者死"，舌体烂损伴热势不退为危重信号；《素问·诊要经终论》"厥阴络者，甚则舌卷、卵上缩而终矣"，舌卷缩为厥阴气绝之征，是短缩舌危重判读的依据。

### 2. 舌形（主虚实、水湿、津液）

| 舌形 | 表现 | 主病 | 白话 |
| --- | --- | --- | --- |
| 胖大舌 | 舌体胖大、边有齿痕 | 脾虚湿盛、阳虚水停 | 舌头又胖又大、边上有牙印，多脾虚湿重、阳虚 |
| 瘦薄舌 | 舌体瘦小薄 | 气血阴液亏虚 | 舌头又瘦又薄，多阴血津液不足 |
| 裂纹舌 | 舌面有裂沟 | 阴液亏虚、热盛伤津、血虚 | 舌头有裂纹，多阴亏、热盛伤津或血虚 |
| 齿痕舌 | 舌边牙齿压痕 | 脾虚湿盛 | 舌边有牙印，多脾虚、湿重 |
| 点刺舌（芒刺） | 舌面红点、高起如刺 | 热盛，脏腑阳热亢盛 | 舌头上有红点尖刺，热重 |
| 光滑舌（镜面舌） | 舌面光洁无苔 | 胃气阴大伤、久病重证 | 舌头光滑如镜，胃阴胃气大伤，病重信号 |

### 3. 舌态（主风动与气血运行）

| 舌态 | 表现 | 主病 | 白话 |
| --- | --- | --- | --- |
| 强硬舌 | 舌体板硬、转动不利 | 热入心包、痰浊内阻、中风先兆 | 舌头发硬转不动，热重、痰阻或中风信号 |
| 痿软舌 | 舌体软弱无力 | 气血阴液大伤 | 舌头软得立不起来，气血阴液大亏 |
| 颤动舌 | 舌体不自主抖动 | 气血两虚、肝风内动 | 舌头不自主地抖，虚极或肝风 |
| 歪斜舌 | 伸舌偏向一侧 | 风痰阻络、中风 | 伸舌歪向一边，中风或风痰信号 |
| 吐弄舌 | 舌伸口外、不即回缩 | 心脾有热、动风先兆（小儿多见） | 舌头老伸在外，心脾有热或动风 |
| 短缩舌 | 舌体卷短、不能伸长 | 寒凝、痰阻、热盛动风、危重 | 舌头缩得伸不开，寒痰热风皆可致，须警惕 |

## 四、舌苔辨证（舌苔看病邪深浅与寒热燥湿）

舌苔由胃气所生，观察苔色与苔质，判断病邪性质与深浅。

### 1. 苔色

| 苔色 | 主病 | 白话 |
| --- | --- | --- |
| 白苔 | 表证、寒证、正常苔 | 白苔多见表证、寒证，薄白苔常为正常 |
| 黄苔 | 里证、热证 | 黄苔多是热，黄色越深热越重 |
| 灰黑苔 | 热极或寒极 | 灰黑苔两极化，干裂多热极，润滑多寒极 |

- 典籍依据：《伤寒论》"阳明病，胁下硬满，不大便而呕，舌上白胎者，可与小柴胡汤"，又"脏结，舌上白胎滑者，难治"，以舌苔白滑辨病位与预后；《温病条辨》阳明温病"面目俱赤，语声重浊，呼吸俱粗，大便闭，小便涩，舌苔老黄，甚则黑有芒刺"，舌苔老黄黑有芒刺为温病热重之征。

### 2. 苔质

| 苔质 | 表现 | 主病 | 白话 |
| --- | --- | --- | --- |
| 薄苔 | 苔薄能见底 | 病浅、正常 | 薄苔病轻或正常 |
| 厚苔 | 苔厚不见底 | 病深、痰湿、食积 | 苔厚说明病邪深、痰湿食积 |
| 腻苔 | 苔细腻致密、刮之难去 | 湿浊、痰湿、食积 | 苔腻黏糊糊的，湿浊痰饮 |
| 腐苔 | 苔质疏松、如豆腐渣 | 食积、痰浊、胃中腐浊 | 苔像豆腐渣，食积痰浊 |
| 润苔 | 苔面湿润 | 津液尚存 | 苔润说明津液没大伤 |
| 燥苔 | 苔面干燥 | 津液已伤 | 苔干是津液受伤 |
| 糙苔 | 苔粗糙干裂 | 热盛伤津重 | 苔又干又裂，热盛津伤重 |
| 剥脱苔（地图舌） | 苔片剥脱、露舌质 | 胃气阴不足、气阴两伤 | 苔一块一块掉，胃气阴不足 |
| 无苔（光剥） | 舌面无苔 | 胃气阴大伤 | 一点苔都没有，胃气阴大伤 |

## 五、舌象与证型对应速查

将舌象直接映射到常见证型，便于辨证落点：

| 舌象组合 | 对应证型 | 白话 |
| --- | --- | --- |
| 舌淡白、苔薄白 | 气血两虚、阳虚 | 舌淡苔白，多虚多寒 |
| 舌红、苔黄 | 实热证 | 舌红苔黄，就是有实热 |
| 舌红、苔黄腻 | 湿热、痰热 | 舌红苔黄腻，湿热或痰热 |
| 舌红、少苔或无苔 | 阴虚内热 | 舌红苔少，阴虚有热 |
| 舌红绛、苔少而干 | 热入营血、阴虚火旺 | 舌深红苔少干，热重或阴虚火旺 |
| 舌淡胖、苔白滑 | 脾虚湿盛、阳虚水停 | 舌淡胖苔白滑，脾虚阳虚水湿重 |
| 舌紫暗、或有瘀斑 | 气滞血瘀 | 舌紫暗有斑，血瘀 |
| 舌红、苔白腻 | 湿热初起、表里同病 | 舌红而苔白腻，湿热或表里同病 |
| 舌淡、苔白厚腻 | 寒湿、痰湿 | 舌淡苔白厚腻，寒湿痰湿 |
| 舌红干、苔黄燥 | 热盛伤津 | 舌红苔黄干，热盛伤津 |

## 六、舌下络脉（瘀血的直观指征）

- 观察方法：让用户翘起舌头，看舌下两条络脉（舌下静脉）。
- 判断标准：络脉细短、颜色淡红为正常；络脉粗长、曲张、颜色青紫或紫暗，多提示气滞血瘀、瘀血内阻。
- 白话要点：舌下血管又粗又紫，瘀血的可能性大，结合舌质紫暗、瘀斑互参。
- 典籍依据：舌下络脉诊法历代医籍有载，《内经》有"舌下络脉"相关论述，具体条文出处与判断标准以原书为准（待核补充）。

## 七、舌诊与五格坐标、证型的对应路径

| 五格 | 舌诊信息对应 | 示例 |
| --- | --- | --- |
| 位置 | 舌面脏腑分属 | 舌尖红定位心肺，舌根苔少定位肾 |
| 性质 | 舌色与苔色定寒热 | 红黄为热，淡白为寒虚 |
| 力量 | 舌形舌态定虚实 | 胖大齿痕为虚为湿，瘦薄为虚为亏 |
| 物质 | 苔质定津液湿浊 | 腻苔定湿浊，燥苔定津伤 |
| 病因 | 舌象反推病因 | 紫暗瘀斑定血瘀，黄腻定湿热 |

- 辨证路径：先定舌质（色、形、态）判脏腑虚实气血，再定舌苔（色、质）判病邪深浅寒热，质苔合参落到证型，与第00册辨证总纲、第07册症状速查表、第32册面诊互参。
- 与面诊合参：面诊定整体病位与神气，舌诊定寒热虚实与邪气深浅，两诊合参更准（见第32册）。

## 八、照片采集要求（第一步使用规范）

用户在病症咨询第一步提供舌头照片时，按以下要求采集，确保辨证可靠：

| 要求 | 说明 |
| --- | --- |
| 光线 | 自然光或明亮白光，避免黄光、滤镜 |
| 伸舌姿势 | 自然伸出舌尖，舌面平展，不要用力过猛或蜷曲，避免舌体变形 |
| 角度 | 舌面正面完整入镜，舌质、舌苔、舌下络脉尽量都拍到 |
| 时机 | 避免刚进食、刚饮茶、刚抽烟、刚刷牙后拍照，这些会染色或改变苔象 |
| 背景 | 深色纯色背景，衬托舌体，避免红黄背景干扰 |
| 补充 | 舌下络脉、侧面形态如有需要可补拍 |

- 使用方式：第一步了解情况时，自然引导用户提供舌头照片，说明"拍张舌头照片，我能看得更准"，不必解释内部辨证逻辑；拿到照片后按本册路径完成舌诊，再与用户所述症状、面诊信息合参。
- 局限声明：照片受光线、设备色彩、伸舌方式影响，舌诊结论须标注"基于照片、须面诊确认"，不能替代执业医师当面望诊。

## 九、安全边界（与第06册一致）

- 舌诊只作为辨证的辅助信息，不替代当面望诊与四诊合参，照片辨证结论须标注局限。
- 舌象出现危重信号（镜面舌、绛舌无苔、短缩舌、舌强不语伴神志异常）时，提示病势重，立即停止辨证、建议就医。
- 舌诊结论须与问诊、面诊、脉诊信息互证，单一舌象不能单独定证。
- 温病高热、急症患者，舌象变化快，照片辨证不能替代及时就医。
