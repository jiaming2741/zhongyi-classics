# 辨证总纲：把一堆症状变成一张可推理的坐标图

## 一、这套方法在解决什么

别人说"我头疼、怕冷、不出汗、浑身酸"，普通人听到的是四句话。中医要做的事，是把这四句话翻译成一个判断：身体现在偏在哪儿、缺什么、多什么、该往哪个方向推回去。这个判断叫"证"。

打个比方。房间太冷，可能是暖气没开，可能是窗户漏风，也可能是温度计坏了。修之前得先分清是哪一种。辨证就是查清"哪种情况"，治法就是"决定开暖气还是关窗"，方药和调理只是执行工具。

所以顺序永远是：症状 → 状态（证） → 方向（治法） → 手段（方药、饮食、作息）。跳步就容易出错。

古籍原文属公有领域，本文件引用的短句均可公开核对。所有白话解释均为原创重写，未复制任何现代整理本或译本。引文以 `references/04-来源版本与版权.md` 登记的底本为准，正式引用前请核对一遍。

## 二、五格坐标法

任何证都能拆成五格。填格的过程就是辨证。

| 格 | 要问自己什么 | 可选答案 |
| --- | --- | --- |
| 位置 | 问题在表层还是里层，在哪条经、哪个脏腑、哪一层 | 表／里／半表半里；太阳／阳明／少阳／太阴／少阴／厥阴；卫／气／营／血；上焦／中焦／下焦；五脏六腑；经络 |
| 性质 | 整体偏冷还是偏热 | 寒／热／寒热错杂／寒热不明显 |
| 力量 | 正气够不够，邪气盛不盛 | 虚／实／虚实夹杂 |
| 物质 | 气、血、津液、阴、阳哪块出岔子 | 气虚、气陷、气滞、气逆、血虚、血瘀、血热、津伤、痰湿、水饮、阴虚、阳虚 |
| 病因 | 什么把平衡推歪的 | 风、寒、暑、湿、燥、火；痰饮、瘀血；怒喜忧思悲恐惊；饮食不节、劳倦、房劳、外伤 |

### 填格示范

用户说：怕冷明显、微微发热、一点汗都没有、头和脖子发紧、全身骨节疼、脉浮紧。

| 格 | 填什么 | 依据 |
| --- | --- | --- |
| 位置 | 表，太阳经 | 恶寒与脉浮同见，头项强痛是太阳经循行部位 |
| 性质 | 寒 | 怕冷重于发热，无汗，喜暖 |
| 力量 | 实 | 起病急，正气未衰，腠理闭住 |
| 物质 | 卫阳被郁，营阴郁滞 | 无汗说明毛窍闭合 |
| 病因 | 风寒外袭 | 受凉后发病 |

对应到《伤寒论》太阳伤寒的提纲范围。反证要不要写？要。若此人汗多、脉缓、怕风明显，就与"实寒无汗"冲突，得改判为太阳中风表虚一类，方向完全不同。

## 三、八纲：四把最基础的尺子

八纲是阴阳、表里、寒热、虚实四对。所有复杂辨证都从这四对起步。

### 表里：病位深浅

| | 表 | 里 | 半表半里 |
| --- | --- | --- | --- |
| 典型表现 | 怕冷发热同时出现，头身痛，鼻塞，脉浮 | 高热不恶寒或只怕冷不发热，腹痛便秘或腹泻，口渴，脉沉 | 冷热一阵一阵来回，胸胁胀满，口苦咽干，心烦喜呕 |
| 常见来源 | 外感初起 | 外邪入里、内伤杂病 | 少阳证 |
| 判断眼目 | 恶寒与发热是否同时存在 | 二便、饮食、口渴的改变 | 寒热往来这四个字 |

《伤寒论》以"脉浮，头项强痛而恶寒"定太阳病提纲，可作为表证的经典锚点。具体条文号与各版本异文见 `references/02-本草与经方.md`。

### 寒热：性质

| | 寒 | 热 |
| --- | --- | --- |
| 主观 | 怕冷，喜暖，喜热饮 | 怕热，喜凉，喜冷饮 |
| 面色 | 偏白或青 | 偏红 |
| 口渴 | 不渴，或喜少量热饮 | 口渴明显，想喝凉水 |
| 二便 | 小便清长，大便稀 | 小便短黄，大便干结 |
| 舌 | 舌淡、苔白润 | 舌红、苔黄干 |
| 脉 | 迟或紧 | 数或洪 |

《神农本草经·序录》讲"疗寒以热药，疗热以寒药"，把用药方向说得最直白。原文短句与出处核对见 `references/02-本草与经方.md`。

真寒假热、真热假寒最容易翻车。遇到"身很热却想盖被、脉很沉很细"或"手脚冰凉却口渴喜冷、大便干结"这类矛盾组合，一律标为"寒热真假待辨，须面诊"，禁止自行下结论。

### 虚实：正气与邪气的力量

| | 虚 | 实 |
| --- | --- | --- |
| 病程 | 久、缓、反复 | 新、急、来势猛 |
| 疼痛 | 隐隐作痛，喜按喜揉 | 胀痛拒按 |
| 精神 | 乏力气短，懒得说话 | 烦躁声高，气粗 |
| 出汗 | 自汗、盗汗 | 无汗或大汗出而热不退 |
| 脉 | 细、弱、无力 | 有力 |
| 治法方向 | 补 | 泻、散、清、通 |

《素问》讲"邪之所凑，其气必虚"（见《评热病论》），意思是邪气能钻进来，往往因为正气先有缺口。这句话解释了为什么同样吹风，有人病有人不病。篇名以 `references/01-医经与诊断.md` 登记为准。

虚实夹杂最常见，例如"脾虚加湿滞"，人又累又胀。此时先补还是先通，要看哪一边更急，输出时必须写清先后理由。

### 阴阳：总纲

阴证大致等于"里＋寒＋虚"的组合，阳证大致等于"表＋热＋实"的组合。具体到脏腑又细分阴虚、阳虚、亡阴、亡阳。《素问·阴阳应象大论》"治病必求于本"，落到操作上就是别只盯着最难受的那个症状，要找到推动全局的那一环。

## 四、脏腑辨证：定位到具体零件

用日常话讲五脏各有分工，失调时的信号也不同。

| 脏腑 | 大白话分工 | 常见证型 | 识别信号 |
| --- | --- | --- | --- |
| 心 | 管血脉与神志 | 心血虚、心阴虚、心火亢、心脉瘀阻 | 心悸、失眠多梦、舌尖红或刺痛、胸闷 |
| 肝 | 管疏泄与藏血，像交通调度 | 肝气郁结、肝火上炎、肝阳上亢、肝血虚、肝风内动 | 情绪一憋就胀，胁肋胀，易怒，头目眩晕，眼干，肢体抽动 |
| 脾 | 管消化吸收与运水，像后勤 | 脾气虚、脾阳虚、中气下陷、脾不统血、寒湿困脾 | 食欲差、饭后胀、大便稀、乏力、身体沉、出血色淡 |
| 肺 | 管气与皮毛，像通风系统 | 肺气虚、肺阴虚、风寒束肺、风热犯肺、痰湿蕴肺 | 咳嗽、气短、易感冒、鼻塞、咽干、痰的色与质 |
| 肾 | 管先天本钱、水液与纳气 | 肾阳虚、肾阴虚、肾精不足、肾不纳气 | 腰膝酸软、怕冷或五心烦热、耳鸣、夜尿多、发育与生殖相关表现 |
| 胃 | 受纳与降浊 | 胃寒、胃热、食滞、胃阴虚 | 胃痛性质、喜按还是拒按、嗳气、饥不欲食 |
| 胆 | 与肝配合，主决断 | 胆郁痰扰、肝胆湿热 | 口苦、胁痛、惊悸失眠、黄疸 |
| 大肠小肠膀胱 | 传导、分清泌浊、排尿 | 湿热、虚寒、津亏 | 二便性状与排便感觉 |

《素问·至真要大论》病机十九条把常见症状归到五脏，例如"诸风掉眩，皆属于肝"，说的就是眩晕振摇一类多从肝论治。完整十九条与白话见 `references/01-医经与诊断.md`。

《金匮要略》开篇讲"见肝之病，知肝传脾，当先实脾"，给出一条很实用的思路：一个脏出问题，要提前护住它最容易牵连的下一个脏。原文核对见 `references/02-本草与经方.md`。

## 五、六经辨证：外感病的六层地图

《伤寒论》把外感病由浅入深划成六层，每层有提纲证。提纲证就是"看到这几条就先想到这一层"。

| 六经 | 提纲大意（白话） | 主方方向 | 一眼抓住的关键 |
| --- | --- | --- | --- |
| 太阳 | 脉浮、头项强痛、怕冷 | 解表，有汗用桂枝类，无汗用麻黄类 | 恶寒与脉浮同在 |
| 阳明 | 胃肠里结实了，或里热蒸腾 | 清法（白虎类）或下法（承气类） | 但热不寒、大汗大渴，或潮热便秘腹满痛 |
| 少阳 | 口苦、咽干、目眩，寒热往来 | 和法，小柴胡类 | 冷热来回＋胸胁苦满 |
| 太阴 | 肚子胀、吐、吃不下、腹泻越来越重 | 温中健脾，理中类 | 腹满自利、喜温喜按 |
| 少阴 | 脉微细、只想睡、畏寒肢冷 | 回阳救逆，四逆类 | 精神极度疲惫＋四肢冷 |
| 厥阴 | 寒热错杂、上热下寒、消渴 | 寒热并调，乌梅丸类 | 症状自相矛盾 |

六经可以传变，也可以合病并病。输出时必须写明"当前判在哪一层"以及"凭什么排除相邻两层"。完整条文号、方剂组成、加减法见 `references/02-本草与经方.md`。

## 六、卫气营血与三焦：温病的另一张地图

《温病条辨》与叶天士一路的温病学说，看的是热邪往里推进的四层深度，以及上中下三个部位。

| 层次 | 白话 | 典型表现 | 治法方向 |
| --- | --- | --- | --- |
| 卫分 | 邪刚到体表防线 | 发热微恶风、咽痛、咳嗽、口微渴、舌尖边红 | 辛凉解表，银翘散、桑菊饮类 |
| 气分 | 邪入里，正邪激烈对抗 | 高热不恶寒、大汗、大渴、脉洪大，或腹满便秘 | 清热生津或通下，白虎、承气类 |
| 营分 | 热伤到营阴与神志 | 身热夜甚、心烦不眠、时有谵语、舌绛 | 清营透热，清营汤类 |
| 血分 | 动血耗血 | 斑疹、出血、舌深绛、神昏抽搐 | 凉血散血，犀角地黄汤类（犀角现代禁用的说明见分册） |

三焦定位：上焦心肺（发热咳嗽、胸闷、神志改变），中焦脾胃（高热、腹满、便秘或湿热困阻），下焦肝肾（手足心热、口干舌燥、抽搐、阴虚风动）。

温病与伤寒的差别要讲清：温病初起以发热渴为主，恶寒轻，用辛凉；伤寒初起以恶寒为主，用辛温。吴鞠通反复强调温病不可随意用辛温发汗，汗后容易变证。原文与条文见 `references/03-温病女科与千金方.md`。

同一个"发热"，两套地图可能给出相反的处理。这正是不看舌脉寒热就套方最危险的地方。

## 七、气血津液：查物质基础

| 类型 | 身体在说什么 | 常见信号 | 方向 |
| --- | --- | --- | --- |
| 气虚 | 动力不足 | 乏力气短、懒言、自汗、动则加重 | 补气 |
| 气陷 | 托举无力 | 久泻、脱肛、内脏下垂感、头晕 | 升提 |
| 气滞 | 堵住了 | 胀痛、部位不固定、随情绪变化 | 行气 |
| 气逆 | 该往下走的往上跑 | 咳喘、嗳气、呕吐、呃逆 | 降气 |
| 血虚 | 滋养不够 | 面色淡、唇甲淡、头晕心悸、女性经量少 | 养血 |
| 血瘀 | 流动不畅 | 刺痛固定、夜间加重、舌有瘀点、肌肤甲错 | 活血 |
| 血热 | 血分有热 | 出血色鲜红、斑疹、心烦 | 凉血 |
| 津伤 | 水液被耗 | 口干、皮肤干、小便少、大便干 | 生津 |
| 痰湿 | 水液没运化好，堆成黏稠垃圾 | 身体沉、痰多、胸闷、苔腻、胖 | 化痰除湿 |
| 水饮 | 水液停在局部 | 水肿、悸动、喘不得卧、肠间有水声 | 温化利水 |

《素问·举痛论》讲"百病生于气也"，把情绪、劳倦、外邪最终都归到气的运行上。白话解释见 `references/01-医经与诊断.md`。

## 八、病因辨证

| 邪气 | 识别特点 | 大白话 |
| --- | --- | --- |
| 风 | 来得快、变化快、游走、常犯上部 | 像一阵风，说变就变 |
| 寒 | 收引、疼痛明显、遇暖减轻 | 像冻住了，管道收缩 |
| 暑 | 夏季、耗气伤津、多夹湿 | 又热又闷又没劲 |
| 湿 | 沉重、黏腻、缠绵难愈、往下走 | 像穿了件湿衣服 |

## 九、九项采集表与判定要点

| 采集项 | 高分信息 | 拿到后能排除什么 |
| --- | --- | --- |
| 寒热 | 恶寒与发热是否同时、谁轻谁重、有无时间规律 | 分表里、分伤寒与温病、分疟类往来寒热 |
| 汗 | 有汗无汗、自汗盗汗、部位、汗后热退与否 | 分表虚表实、分阴虚、分气分热 |
| 头身 | 疼痛性质（胀／刺／隐／重）、部位、喜按拒按 | 分虚实、分气滞血瘀湿重 |
| 口渴与饮食 | 渴不渴、喜冷喜热、食欲、口味 | 分寒热、分津伤、分胃气 |
| 二便 | 便质、次数、颜色、气味、排便感觉 | 分寒热虚实、分肠胃与下焦 |
| 睡眠情绪 | 入睡难还是易醒、多梦、烦躁或抑郁 | 分心肝、分营血分 |
| 舌 | 舌质淡红绛紫、苔白黄腻少、润燥 | 校对寒热虚实最硬的客观指标 |

用户不会描述舌脉时跳过，写明"舌脉未提供，置信度下调一档"，禁止猜。

## 十、脉象与舌象的极简速查

| 脉 | 手感白话 | 常见指向 |
| --- | --- | --- |
| 浮 | 轻按就摸到，重按变弱 | 表证 |
| 沉 | 轻按摸不到，重按才清楚 | 里证 |
| 迟 | 一呼一吸不足四次 | 寒 |
| 数 | 一呼一吸超过五次 | 热 |
| 虚／弱 | 细而无力 | 虚 |
| 实／滑 | 有力，滑如盘走珠 | 实、痰湿、食滞、妊娠可见 |
| 弦 | 像按琴弦，端直绷紧 | 肝胆、气郁、疼痛、痰饮 |
| 细 | 细如线 | 血虚、阴虚 |
| 紧 | 绷急有力如转索 | 寒、痛 |
| 结代 | 跳跳停停有规律或无规律 | 心气心血问题，须就医评估 |

## 十一、防翻车清单（每次下结论前逐条过）

1. **硬套方子**：只因为看到"头痛"就给某个方。对策：先填五格，再找方。
2. **忽略反证**：只列支持点。对策：每个候选证型至少写一条不支持点或"暂无反证，但缺舌脉核对"。
3. **病名等于证型**：看到西医诊断就套中医证。对策：只认当下症状体征。
4. **寒热真假**：矛盾组合出现时继续硬判。对策：标"须面诊"，停下。
5. **虚实先后说不清**：虚实夹杂时不写先补还是先通的理由。对策：必写理由。
6. **剂量穿越**：把汉制剂量直接当克数给患者。对策：只讲原书记载与争议，剂量一律由医师核定。
7. **引用幻觉**：凭印象写篇名条文号。对策：查 `references/`，查不到写"待核"。
8. **版本异文**：不同底本文字不同却不加说明。对策：注明依据分册登记的底本。
9. **安全漏项**：忘写免责、忘排红旗、忘标特殊人群。对策：过 `references/06-安全边界与输出规范.md`。
10. **信息不足还高置信**：对策：降档并列出需补项。

## 十二、同症异治与异病同治

同一个"头痛"，受凉后项背发紧无汗属太阳表实，情绪憋闷后两侧胀痛属肝气郁，劳累后隐隐空痛属气血虚，头重如裹伴苔腻属湿。处理方向完全不同。

反过来，失眠、心悸、月经不调若都指向血虚，调理方向可以相通。判断依据落在证上，落在症状组合上。
