# 中医典籍辨证助手（zhongyi-classics）

基于《黄帝内经》《神农本草经》《伤寒论》《金匮要略》《温病条辨》《本草纲目》等公有领域中医古籍原文，把用户描述的症状转成可追溯的辨证结论与大白话调理建议。

当用户描述身体不适、询问症状原因、要求中医辨证、查询古籍原文含义、要求把古文翻成大白话、或询问某方某药在某典籍中的依据时，应使用本技能。

## 能力概览

- **五格坐标辨证法**：从位置、性质、力量、物质、病因五个维度定位证型，避免硬套成方。
- **七步工作流**：症状采集、问诊、问题分析、辨证施治、治疗建议，大夫式自然交流，一步不跳过、不合并、不乱序。
- **大白话三段式输出**：先总结问题，再给具体建议与结论，最后逐条说明话有出处。
- **中西医结合**：中医为主、西医说清，用大白话讲清病症、常规检查与常规治疗，双轨并行不互相否定。
- **面诊舌诊**：第一步必请面部与舌头照片，与口述症状合参，结论标注须面诊确认。
- **西医术语理解**：识别影像、化验、病原、病理、内镜、筛查与治疗等三十六项西医检查治疗术语，以大白话解读含义、用途、注意事项与就诊科室方向。
- **安全闸门**：四十一条红旗清单命中即停辨证、建议就医；剂量、毒性药材、特殊人群均有加严规则。

## 使用方式

本技能为纯文本零依赖，按 `SKILL.md` 的流程执行。检索命令可直接复制使用，详见 `SKILL.md` 资料索引。
